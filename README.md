# 📱 Mobile Sales Analytics Dashboard

An interactive Power BI dashboard designed to analyze mobile sales performance, customer trends, and product insights through dynamic and visually engaging reports.

---

# 📌 Short Description / Purpose

The Mobile Sales Analytics Dashboard is a data visualization project built in Power BI to explore sales performance across different mobile brands, products, and regions.

This dashboard helps users identify sales trends, compare product performance, track revenue metrics, and gain business insights through interactive visuals and KPIs. The project was created as part of my learning journey in data analytics and dashboard development.

---

# 🛠️ Tech Stack

The dashboard was built using the following tools and technologies:

- 📊 Power BI Desktop – Main platform used to build interactive dashboards and reports.
- 📂 Power Query – Used for data cleaning, transformation, and preprocessing.
- 🧠 DAX (Data Analysis Expressions) – Used to create calculated measures and KPIs.
- 🔗 Data Modeling – Relationships created between tables for accurate filtering and analysis.
- 📈 Data Visualization – Charts, KPI cards, slicers, and graphs for business storytelling.
- 📁 File Format – `.pbit` for Power BI template and `.png` for dashboard previews.

---

# 📂 Data Source

The dataset used for this project contains mobile sales-related information such as:

- Mobile brands and models
- Sales revenue
- Product categories
- Regional sales performance
- Customer purchase trends
- Quantity sold and transaction details

The dataset was used for practicing real-world business analysis and dashboard creation in Power BI.

# ✨ Features / Highlights

## 📌 Business Problem

Mobile companies generate large volumes of sales data daily, but raw datasets alone make it difficult to quickly identify:

- Best-selling mobile brands
- Revenue trends over time
- High-performing regions
- Customer purchasing behavior
- Product categories driving maximum sales

Without proper visualization, decision-making becomes slower and less effective.

---

## 🎯 Goal of the Dashboard

The main goal of this dashboard is to:

- Transform raw sales data into meaningful insights
- Create an interactive and easy-to-understand reporting system
- Analyze sales performance across products and regions
- Practice dashboard development and storytelling using Power BI

---

# 📊 Walkthrough of Key Visuals

## 🔹 KPI Cards
Displays important business metrics such as:
- Total Sales
- Total Revenue
- Total Orders
- Total Quantity Sold

These KPIs provide a quick overview of overall business performance.

---

## 🔹 Sales Trend Analysis
Line and area charts help visualize:
- Monthly sales growth
- Revenue trends over time
- Seasonal sales patterns

This helps identify periods of high and low sales performance.

---

## 🔹 Brand Performance Analysis
Bar charts compare mobile brands based on:
- Revenue generated
- Quantity sold
- Customer demand

Helps identify top-performing brands in the market.

---

## 🔹 Regional Sales Insights
Interactive visuals display sales performance by:
- Region
- City
- Market area

Useful for understanding geographic business trends.

---

## 🔹 Product Category Breakdown
Visuals showing:
- Product-wise contribution
- Sales distribution
- Category performance

Helps analyze which products contribute most to total revenue.

---

## 🔹 Interactive Filters & Slicers
Users can dynamically filter the dashboard using:
- Brand
- Region
- Category
- Time Period

Improves user experience and data exploration.
